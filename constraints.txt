# Exact versions for every package in the tested environment, transitive ones
# included. requirements.txt pins only what the app imports directly, so without
# this file `pip install -r requirements.txt` still resolves httpx, pydantic,
# pyobjc-core and the rest fresh on every install. Two people installing weeks
# apart would then freeze different dependency trees into their bundles.
#
# A constraint installs nothing by itself. It only fixes the version of a package
# that something else asks for, so the dev-only and build-only entries here
# (pytest, ruff, py2app) have no effect on an end-user runtime install.
#
# Used by scripts/start.sh, scripts/install.sh and .github/workflows/ci.yml:
#
#   pip install -r requirements.txt -c constraints.txt
#   pip install -r requirements-dev.txt -c constraints.txt
#   pip install py2app -c constraints.txt
#
# Frozen from a Python 3.13 virtualenv with every requirements file installed,
# plus py2app. Regenerate after changing any pin, then re-run the test suite:
#
#   uv pip freeze --color never -p .venv/bin/python | grep -v -e '^-e' -e ' @ '
#
# Editable and local-path entries are excluded; they are not installable elsewhere.
