INSTALLATION & SUPPORT

Common questions

How do I install a direct download?

Unpack the source archive on an Apple silicon Mac with Python 3.13. Open the included installation guide for the setup and launch steps. The Mac App Store edition uses Apple’s installer.

What can Premium repair?

It can attempt a DNS cache flush and other supported local repairs. Some steps require administrator permissions. Failover needs a working backup connection and prior configuration. The incident report records the result of each attempted step.

Where are my logs kept?

Incident reports are stored on your Mac. Sharing them is up to you. The app only uses optional external integrations when configured. See the privacy notice for details.

How do I download Premium after paying?

Checkout returns you to your private order page. Download the archive there and save that page’s address for later access.
