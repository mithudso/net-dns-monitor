# Net DNS Monitor documentation

Net DNS Monitor is a macOS menu-bar application with a command-line interface, an optional headless monitor and a separate signed-UDP fleet report server.

- [Architecture](Architecture.md) explains the maintained roles and data flow.
- [Development](Development.md) links setup and contribution checks.
- [Testing](Testing.md) describes synthetic verification and its limits.
- [Operations](Operations.md) links supported repair, fleet and release procedures.
- [Security](Security.md) describes trust boundaries and reporting.

These pages are an offline navigation layer over the repository documentation. They do not establish that a service is installed, a network repair has run, or an App Store build is approved.
