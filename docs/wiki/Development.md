# Development

Start with [installation](../INSTALLATION.md), [development setup](../DEVELOPMENT.md) and [onboarding](../onboarding.md). The project uses Python 3.13 or newer and four declared runtime packages. Test and lint tools are separate from the runtime requirements.

Use the repository's pinned requirements and constraints. Run the checks in [testing](../TESTING.md) before delivery. Read [CLAUDE.md](../../CLAUDE.md) for repository conventions and append-only workflow journals.

[The static retrieval guide](../llms/llms.txt) is available without a semantic index. Optional MCP/index tooling has separate dependencies and can invoke an embedding service; a static documentation refresh does not require starting it.
